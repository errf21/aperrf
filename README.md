## ✨ ویژگی‌ها

- 🪄 **بدون دیتابیس** — همهٔ داده‌ها در یک فایل JSON (`data/db.json`)
- 👤 **تنظیم یک‌باره** — در اولین بازدید از مسیر `/setup` نام‌کاربری و رمز ساخته می‌شود
- 🌐 **سه پروتکل انتقال برای هر کاربر** — VLESS/WS (`/vl-ws`)، VMess/WS (`/vm-ws`) و VLESS/XHTTP (`/vl-xhttp`)، همگی روی پورت ۴۴۳ با TLS
- 📊 **محدودیت‌های پیشرفتهٔ کاربران** — حجم (GB)، روز اعتبار، سقف تعداد درخواست و قطع خودکار
- 🔌 **مدیریت اتصالات** — سقف اتصال همزمان + قفل روی اولین IP
- ⚙️ **تنظیمات سراسری کانفیگ** — Fingerprint، ALPN، SNI اختصاصی (Domain Fronting)، پیشوند و نام اختصاصی هر کانفیگ در اشتراک، و Fragment (Packets / Length / Interval)
- 🔗 **لینک اشتراک سازگار با v2rayNG** — خروجی متن سادهٔ Base64 با هدر `Subscription-Userinfo` (نمایش مصرف/حجم/اعتبار) + خروجی JSON جداگانه
- 📈 **کانفیگ نمایشی وضعیت** — مصرف و روزهای باقی‌مانده داخل خودِ اشتراک نمایش داده می‌شود
- 🖼 **QR code** برای کانفیگ TLS
- 🛑 **ابطال آنی لینک‌ها** — با چرخش UUID (regenerate)
- 🧼 **ریست مصرف** به ازای هر کاربر
- 📱 **صفحهٔ وضعیت عمومی** — رصد مصرف بدون نیاز به ورود (+ API JSON آن)
- 🔐 **سرور DoH داخلی** — مسیر `/dns-query` (Cloudflare با fallback به Google)؛ قابل استفاده در DNS امن مرورگر و کلاینت‌ها
- 📊 **نمودار ترافیک ساعتی** (۲۴ ساعت اخیر، نگهداری ۷۲ ساعت) + ترافیک به تفکیک کاربر
- 👥 **شمارش کاربران فعال** بر اساس آخرین ترافیک (۳۰ ثانیهٔ اخیر) — بدون وابستگی به netstat
- 🌍 **مکان‌یابی خودکار سرور** — از Cloudflare colo (شهر و کشور)
- ⏱ **بیدارباش خودکار (Keep-Alive)** — پینگ داخلی هر ۱۰ دقیقه (قابل خاموش‌کردن)
- 🌗 **تم تاریک/روشن + دوزبانهٔ فارسی/انگلیسی (RTL)** با فونت‌های محلی
- 🎵 **موسیقی پس‌زمینهٔ اختیاری** — کلید پخش در تنظیمات
- 💬 **دکمهٔ پشتیبانی تلگرام** — دسترسی سریع ([t.me/Espierz](https://t.me/Espierz))

## 🧱 معماری (تک‌سرویس)

در حالت استاندارد (Docker/Railway) همه‌چیز در یک کانتینر اجرا می‌شود؛ Nginx تنها نقطهٔ ورود عمومی است و ترافیک پنل و پروکسی را روی یک پورت تفکیک می‌کند:

| کامپوننت | پورت | نقش |
|----------|------|-----|
| Nginx | `$PORT` (پیش‌فرض `8000`) | ورودی عمومی — مسیرهای `/vl-ws`، `/vm-ws`، `/vl-xhttp` به Xray و بقیهٔ درخواست‌ها به پنل |
| پنل aperrf (FastAPI + uvicorn) | `10000` (داخلی) | رابط وب و API |
| Xray — VLESS/WS | `10001` (داخلی) | پروکسی مسیر `/vl-ws` |
| Xray — VMess/WS | `10002` (داخلی) | پروکسی مسیر `/vm-ws` |
| Xray — VLESS/XHTTP | `10004` (داخلی) | پروکسی مسیر `/vl-xhttp` |
| Xray Stats API | `10085` (داخلی) | خواندن مصرف هر کاربر (delta هر ۵ ثانیه) |

سمت کلاینت، هر سه کانفیگ روی پورت ۴۴۳ اتصال HTTPS برقرار می‌کنند؛ TLS توسط خود پلتفرم (Railway/Render/Cloudflare) مدیریت می‌شود.

## 🚀 نصب و دیپلوی

### 🚂 Railway (توصیه‌شده)

1. ریپازیتوری را Fork یا push کنید.
2. در [railway.app](https://railway.app) → **New Project → Deploy from GitHub repo** — فایل `railway.json` به‌طور خودکار شناسایی شده و build از روی `Dockerfile` انجام می‌شود (پنل + Xray + Nginx در یک سرویس).
3. پس از دیپلوی، دامنهٔ عمومی سرویس را باز کنید و مسیر `/setup` را ببینید.

> 💡 Railway آی‌پی اختصاصی ارائه می‌دهد (نه بک‌اند Cloudflare). در صورت فیلتر شدن، حالت Fragment را هم از پنل (تنظیمات → تنظیمات پیشرفتهٔ کانفیگ) و هم در کلاینت فعال کنید.

### 🌐 Render

1. ریپازیتوری را به GitHub push کنید.
2. در [render.com](https://render.com) → **New → Web Service** → اتصال ریپازیتوری؛ فایل `render.yaml` به‌صورت خودکار شناسایی می‌شود (name: `aperrf`, env: python, build: `pip install -r requirements.txt`, start: `python main.py`).
3. بعد از دیپلوی به مسیر `/setup` بروید.

> ⚠️ توجه: `render.yaml` سرویس را **بدون Docker** (بدون Nginx و Xray) دیپلوی می‌کند؛ در این حالت رابط پنل، تنظیمات، اشتراک‌ها و صفحهٔ وضعیت در دسترس‌اند، ولی اتصال پروکسیِ کانفیگ‌ها (نیازمند Xray) برقرار نمی‌شود. برای سرویس کامل، روش Railway/Docker توصیه می‌شود.

### 💻 اجرای محلی (Python)

پیش‌نیاز: Python 3 (تست‌شده با ۳.۱۱)

```bash
git clone https://github.com/<your-username>/aperrf.git
cd aperrf
pip install -r requirements.txt
python main.py
# → Setup: http://127.0.0.1:10000/setup
```

> ⚠️ پنل روی `127.0.0.1` و پورت `PANEL_PORT` (پیش‌فرض ۱۰۰۰۰) اجرا می‌شود. اگر باینری `xray` در `/usr/local/bin/` موجود نباشد، پنل در حالت مدیریتی (بدون پروکسی واقعی) کار می‌کند — برای استک کامل از داکر استفاده کنید.

### 🐳 اجرای محلی با داکر (پنل + Xray + Nginx)

```bash
docker build -t aperrf .
docker run -p 8000:8000 aperrf
# → Setup: http://localhost:8000/setup
```

## 🧭 راه‌اندازی اولیه

1. بازدید از `<your-domain>/setup`
2. ساخت نام‌کاربری و رمز عبور (اعتبار مدیریتی برای کل عمر نصب)
3. پس از ورود، کاربران را در بخش **کاربران (Inbounds)** بسازید — حجم، اعتبار، سقف اتصال/درخواست، Fingerprint و قفل IP.
4. در **تنظیمات** → **تنظیمات پیشرفتهٔ کانفیگ** می‌توانید پروتکل‌های انتقال، Fragment و نام کانفیگ‌ها را مدیریت کنید.
5. از مودال **لینک‌ها** برای هر کاربر: اشتراک v2rayNG، QR، لینک وضعیت عمومی، خروجی JSON و آدرس DoH را کپی کنید.

## 🔧 متغیرهای محیطی

| متغیر | پیش‌فرض | توضیح |
|-------|---------|-------|
| `PORT` | `8000` | پورت گوش‌دادن Nginx در ایمیج داکر/Railway (روی پلتفرم به‌صورت خودکار ست می‌شود) |
| `PANEL_PORT` | `10000` | پورت داخلی پنل؛ uvicorn روی `127.0.0.1` می‌نشیند و Nginx آن را پروکسی می‌کند |
| `STANNG_DATA_DIR` | `./data` | پوشهٔ ذخیرهٔ `db.json` (برای پشتیبان‌گیری یا مانت کردن volume) |

> 📝 در این نسخه متغیرهایی مثل `SECRET_KEY` یا `BASE_PATH` وجود ندارند — کلید امضای سشن هنگام اولین اجرا تولید شده و داخل `data/db.json` ذخیره می‌شود.

## 🔒 نکات امنیتی

- **رمز عبور:** هش PBKDF2-HMAC-SHA256 با ۲۶۰٬۰۰۰ تکرار و salt اختصاصی.
- **قفل ورود:** پس از ۶ تلاش ناموفق از هر IP، ۵ دقیقه مسدودسازی (وضعیت `429 locked`).
- **سشن:** کوکی امضاشده (itsdangerous)، `HttpOnly` و `SameSite=Lax` با اعتبار ۷ روز؛ با تغییر رمز، سشن‌های قبلی باطل می‌شوند.
- **محافظت از فایل `data/db.json`:** تمام داده‌های حساس (هش ادمین، UUID کاربران، کلید سشن) اینجاست. مسیر وب برای آن باز نیست، ولی از دسترسی مستقیم فایل‌سیستمی/وب‌سرور دیگر جلوگیری کنید.
- **نشت لینک اشتراک:** دکمهٔ **regenerate** (API: `/api/inbounds/{uid}/regenerate`) UUID را عوض می‌کند؛ لینک‌ها و کلاینت‌های قبلی بی‌اثر می‌شوند.
- **HTTPS:** Railway/Render به‌صورت پیش‌فرض TLS ارائه می‌دهند؛ در هاست شخصی خودتان لایهٔ TLS را (مثلاً با Cloudflare یا reverse proxy) فعال کنید — کانفیگ‌ها پورت ۴۴۳ با TLS فرض می‌کنند.
- **OTA حذف‌شده:** این نسخه هیچ سازوکار خود-به‌روزرسانی‌کنی ندارد؛ کد فقط با جایگزینی فایل‌ها/ریدپلوی آپدیت می‌شود.
